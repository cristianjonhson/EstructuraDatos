# Estructura de Datos con SQL

Este proyecto está orientado a aprender y practicar estructuras de datos utilizando SQL. Aquí encontrarás ejemplos, scripts y documentación para cada estructura de datos implementada en SQL.

## Estructura del proyecto

- `sql/` — Scripts SQL para cada estructura de datos
- `README.md` — Documentación general y guía de uso

## ¿Qué encontrarás aquí?
- Tablas y scripts para:
  - Listas
  - Pilas (Stacks)
  - Colas (Queues)
  - Árboles
  - Grafos
- Ejercicios y ejemplos prácticos

## Cómo usar este repositorio
1. Clona el repositorio o descarga los archivos.
2. Utiliza los scripts SQL en tu gestor de base de datos favorito (MySQL, PostgreSQL, SQL Server, etc).
3. Lee la documentación y sigue los ejemplos.
